# Evidence Acquisition Log

## Project

Terac AI Cybersecurity Training — Module 1: Cryptographic Security Evaluation

## Purpose

This document records the methods used to collect and maintain evidence
during the educational cryptographic security evaluation.

## Evidence Sources

Evidence was collected from:

- The local OWASP Juice Shop educational lab environment.
- Local cryptographic analysis scripts.
- RSA-OAEP comparison demonstrations.
- Python security evaluator output.
- Authorized local directory discovery and file-access testing.

## Collection Methods

The evidence collection process included:

1. Recording the testing scope and environment.
2. Running the relevant local analysis scripts.
3. Capturing cryptographic evaluation results.
4. Recording directory discovery and file-access observations.
5. Comparing deterministic encryption behavior with RSA-OAEP.
6. Retaining reports and supporting text files for review.

## Evidence Integrity

Evidence files should be preserved in their original form wherever
practical.

Any corrections, redactions, or transformations should be documented.
Sensitive credentials, personal information, and unrelated confidential
business information must not be included in the public portfolio.

## Limitations

This is an educational project. The evidence reflects observations
from the local lab and supporting source-code analysis. It does not
represent an independent production-system security audit.
